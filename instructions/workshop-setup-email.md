---

## TL;DR

1. Request Claude Code access at [developer.disney.com/ai-tools](https://developer.disney.com/ai-tools)
2. Get manager approval
3. Run our setup script for your machine
4. Verify installation

---

## Step 1: Request Claude Code Access

Visit [developer.disney.com/ai-tools](https://developer.disney.com/ai-tools) and request access to **Claude Code**. As part of the pilot group, you'll see this option available. Fill out the use case and accept the AI usage guidelines.

**Manager Approval:**
- Your manager will receive an approval request via Email and Teams
- They can approve directly from the link or visit [developer.disney.com/ai-tools/approvals](https://developer.disney.com/ai-tools/approvals)
- Once approved, you'll be added to the AWS Bedrock account

**Note:** If you're a manager, director, or above - this step will be approved automatically.

---

## Step 2: Set Up Your Development Machine

We've created a **setup script** that installs all the tools you need. Choose the link based on what your team uses:

- **GitHub users:** [github.disney.com/FONAA001/central-claude-code](https://github.disney.com/FONAA001/central-claude-code)
- **GitLab users:** [gitlab.disney.com/ai-workshops/central-claude-code](https://gitlab.disney.com/ai-workshops/central-claude-code)
- **Not using either?** Use the GitHub link

This script installs the required tools (`awsmyid` and `claude`) and configures your environment.

---

## Step 3: Verify Your Setup

Open your terminal and run these commands:

```bash
awsmyid --version
claude --version
```

If both return version numbers, you're all set! ✅
