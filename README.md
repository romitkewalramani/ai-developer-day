# Disney AI Developer Day

A hands-on one-day workshop on collaborating effectively with AI development tools, specifically Claude Code.

## Workshop Topics

### Session 1: Setup & Environment

- Environment setup and validation
- AI development tool comparison (Cursor, Claude Code, Q Developer, GitHub Copilot)
- Getting started exercises

### Session 2: Vibe Coding Fundamentals

- Context management and model selection
- Rules and memory configuration
- **Lab:** Build EmojiHub API integration project

### Session 3: Advanced Techniques

- Token optimization strategies
- Multi-agent systems introduction
- **Lab:** Enhance projects with multi-agent coordination

### Session 4: MCP Ecosystem

- Model Context Protocol fundamentals
- Off-the-shelf MCP servers (Sequential Thinking, GitLab, Playwright, Context7)
- **Lab:** Build your first custom MCP server
